# Cadizo WordPress Downloads

Official direct-download packages for Cadizo WordPress plugins.

Download a ZIP from [Releases](../../releases), then install it from WordPress
Admin: **Plugins -> Add New -> Upload Plugin**. Upload the ZIP directly; do not
unzip it first.

Install **Cadizo Hub** first. It connects a WordPress site to one Cadizo account
so every installed Cadizo plugin shares the same Cadizo Credits balance and site
connection. Each AI request is metered by the Cadizo service; plugins do not
include a model key or a free inference path.

The first recommended workflow is Cadizo Hub, Content Audit, Readability
Rewrite, and SEO Optimizer. Product Pages, Media Optimizer, and Media Library
Search form a second workflow.

This repository intentionally contains release artifacts only. Cadizo's service
source, server-owned prompts, billing implementation, credentials, and internal
tests remain in a separate private repository.

Support and product documentation: https://api.cadizoweb.com/support
